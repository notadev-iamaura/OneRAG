# 한국어·영어 문서 QA 평가 결과

한국어 단일 기사에서 답과 인용 위치를 함께 확인하는 설정은 가장 최근의 KLUE 표본에서 **근거 정답 58/80(72.5%)**, **올바른 보류 62/80(77.5%)**를 기록했다. 한국어 위키백과 문단을 검색하는 TyDi에서는 두 표본 모두 보류율이 80%를 넘었고 정답률은 절반 이하였다. 현재 측정으로는 두 지표 모두 80%라는 목표를 충족하지 못했다. [기계 판독용 집계 및 원본 성적표 해시](rag-quality-counts.json)

## 한국어 정책 비교

| 공개 데이터와 표본 | 기존 → 유지한 방식의 근거 정답 | 기존 → 유지한 방식의 올바른 보류 | 비교 시점 |
|---|---:|---:|---|
| KLUE 1차, 160문항 | 53 → 54 / 80 | 60 → 60 / 80 | 기존 성적 확인 후 원응답 재채점 |
| KLUE 2차, 64문항 | 21 → 22 / 32 | 23 → 23 / 32 | 기존 성적 확인 후 원응답 재채점 |
| KLUE 3차, 160문항 | 57 → 58 / 80 | 62 → 62 / 80 | 성적 공개 전 보정 정책과 채점 기준 등록 |
| TyDi 1차, 48문항 | 12 → 12 / 24 | 21 → 21 / 24 | 독립 비교 후 기존 방식 유지 |
| TyDi 2차, 32문항 | 7 → 7 / 16 | 15 → 15 / 16 | 독립 비교 후 기존 방식 유지 |

KLUE에서는 같은 검색 1위 기사와 같은 로컬 Qwen 응답으로 기존 방식과 보정 방식을 비교했다. 3차에서 정답 기사가 1위였던 77문항 중 58개를 맞혔다. 긍정 답변을 표시한 88건 중 출처·인용까지 정확한 답은 58건이었다. 답이 없는 80문항 중 17건에서 답을 표시했고, 1건은 처리 오류였다.

TyDi는 문단 8개를 검색했다. 1차에서 정답 문단을 찾은 수는 19/24건, 실제 표시한 답 중 엄격 정답은 12/19건이었다. 문장 기반 후보는 정답이 9/24로 줄었다. 2차에서는 정답 문단을 16/16건 찾았지만 실제 표시한 답 중 엄격 정답은 7/14건이었다. 두 번째 후보도 기존 정답 건수를 늘리지 못했다.

KLUE 세 표본은 공식 학습 분할에서 로컬 학습과 이전 평가의 질문·기사와 겹치지 않게 예약했다. TyDi 두 표본은 공식 검증 분할에서 뽑았다. TyDi 양성은 둘 이상의 주석자가 동일 문단·구절에 동의했고, 음성은 세 주석자 모두 원 기사에서 답·문단·예/아니오 응답을 지정하지 않은 경우다. 공개 모델의 사전학습 문서 노출 이력은 확인할 수 없다. 양성·음성이 같은 수인 표본의 비율을 고객 트래픽에 그대로 적용하기는 어렵다. [KLUE-MRC 데이터](https://huggingface.co/datasets/klue/klue/tree/349481ec73fff722f88e0453ca05c77a447d967c/mrc) · [TyDi QA 데이터](https://huggingface.co/datasets/google-research-datasets/tydiqa/tree/da78f23f9119363459acbaf46bf89426ff26c259/primary_task)

## 같은 개발 문항에서 모델 교체

KLUE 공식 검증 분할에서 구성한 개발 80문항 중, 미리 선택한 24문항을 세 모델에 반복 사용했다. 512개 기사에서 검색한 같은 1위 기사를 읽게 했다. 생성 직후의 두 열은 동일한 규칙으로 원문에서 답이 처음 등장하는 위치를 채점한다. 제품 처리 후의 두 열은 최종 답과 인용 위치를 함께 평가한다.

| 모델 | 생성 직후 근거 정답 | 생성 직후 올바른 보류 | 제품 처리 후 근거 정답 | 제품 처리 후 올바른 보류 |
|---|---:|---:|---:|---:|
| Qwen 35B 로컬 | 6/12 | 10/12 | 7/12 | 10/12 |
| GPT-5.4 | 4/12 | 10/12 | 6/12 | 9/12 |
| GPT-6 Luna | 4/12 | 9/12 | 6/12 | 9/12 |

Luna에서 정답 기사는 검색 상위 8개에 12/12건, 모델이 읽은 1위에 11/12건 포함됐다. 정답 기사를 읽은 경우에도 엄격 정답은 6/11건이었다. 제품이 답을 표시한 13건 중 6건이 정확했다. 답이 없는 질문에 답한 경우는 3건, 답이 있는 질문을 잘못 보류한 경우는 2건이었다. 이 비교는 재사용한 개발 표본의 결과다.

같은 24문항의 저장된 모델 응답과 근거를 최신 한국어 보정 정책에 다시 넣었다. **Luna는 근거 정답 7/12, 올바른 보류 9/12**, **로컬 Qwen은 8/12, 10/12**가 됐다. 각각 이전 오답 1건을 바로잡았고 올바른 보류 수는 같았다. 두 재생 모두 추가 모델 호출 0건, 처리 오류 0건이었다. 이 수치는 정책 함수에서 수행한 오프라인 진단이다. 실제 제품에서 원격 Luna를 이 설정으로 실행한 이력은 없다. [최신 정책의 개발 집계](rag-quality-counts.json)

## 이전 한국어·영어 평가

이전 제품 정책은 한국어 KLUE, 한국어 TyDi, 영어 SQuAD 주 표본·재현 표본, 영어 TyDi의 384문항에서 측정했다. 각 표본마다 근거 정답과 올바른 보류가 모두 80% 이상이어야 통과한다. 다섯 표본 중 영어 SQuAD 재현 표본만 양쪽을 통과했다. 위 한국어 후속 실험과 평가 문항 및 제품 구성이 다르다. [표본 구성과 고정된 해시](../../output/rag-growth-03/public-suite.json)

| 표본 | 근거 정답 | 올바른 보류 |
|---|---:|---:|
| 한국어 KLUE | 57/80 | 58/80 |
| 한국어 TyDi | 5/24 | 23/24 |
| 영어 SQuAD 주 표본 | 25/32 | 30/32 |
| 영어 SQuAD 재현 표본 | 28/32 | 27/32 |
| 영어 TyDi | 15/24 | 14/24 |

## 검증 방법

정답은 허용 답 표현, 출처 문서, 실제로 반환한 인용문 및 해당 원문 내 주석 위치까지 대조한다. 보류는 근거가 없는 문항에서 제품이 명시적으로 보류하고 인용을 비운 경우다. 시간 초과·잘못된 인용·모델 오류는 분모에 포함한다. 다음 합성 회귀 검사는 모델 호출 없이 임시 디렉터리에 답변·문서·라벨을 생성해 채점 로직과 오류 처리를 검증한다.

```sh
ENVIRONMENT=test uv run pytest -q tests/unit/scripts/test_rag_growth_public_gate.py \
  tests/unit/agent/test_verified_korean_evidence.py
```

저장소에는 집계, 점수의 분모, 원본 성적표의 SHA-256을 제공한다. 원문 코퍼스, 모델 체크포인트, 실행별 질문·응답 및 인용은 측정 환경에 보관한다. 과거 실험을 문항 단위로 재생하려면 등록 당시 해시와 일치하는 소스 및 당시 입력도 필요하다. 아래 명령은 원래 실행 디렉터리가 있는 환경에서 공개 집계의 모든 수치와 성적표 해시를 다시 대조한다. 새 데이터를 준비해 평가하는 방법은 로컬 실행 가이드에 있다. [집계 코드](export_rag_quality_counts.py) · [로컬 실행 절차](rag-growth-local.md)

```sh
python docs/release-readiness/export_rag_quality_counts.py --source-root "$LOCAL_RUNS" \
  --check docs/release-readiness/rag-quality-counts.json
```
